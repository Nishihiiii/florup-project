## 9. Проблемы, оставшиеся неисправленными, и причины

1. **Отсутствие серверного рендеринга (SSR):** приложение реализовано как клиентский SPA (Vite + React). Переход на SSR требует смены архитектуры роутинга и сборки (миграция на Next.js или React Router v7 framework mode), что не выполняется в рамках аудита.
2. **Внешние запросы к тайлам OpenStreetMap и Overpass API на `/map`:** скорость загрузки карты зависит от стороннего сервиса, однако сама страница вынесена в `lazy()`-чанк и не влияет на производительность остальных маршрутов.
