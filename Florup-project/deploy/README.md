# Деплой приложения на выбранный хостинг: настройка серверов, SSL, домен, интеграция с CI/CD

Проект:** Florup (веб-путеводитель по уходу за комнатными растениями)

## 1. Архитектура проекта при развертывании

Проект развернут локально в продакшен-режиме с использованием Docker Compose и единой точки входа через обратный прокси-сервер **nginx** (`gateway`) по протоколу HTTPS на локальном домене `https://florup.localhost`. База данных PostgreSQL размещена в облаке **Supabase**, поэтому отдельный контейнер БД не поднимается — сервис `api` подключается к ней по сети. Информация о магазинах на карте подтягивается из внешнего API OpenStreetMap (Overpass API).

```text
Браузер (https://florup.localhost)
        │  HTTPS (443) / HTTP -> 301 HTTPS (80)
        ▼
